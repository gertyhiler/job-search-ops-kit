# Developer Skills

The root `.agents/skills/` directory is reserved for **developer-mode** skills only.

- Do not place production/operator role skills here.
- Production skills live under `operator/.agents/skills/` in source form.
- The installer copies production skills into the installed operator app workspace.

If developer-only skills are added later, place them here and keep them scoped to source-repo work such as architecture, refactors, verification, or tooling.
